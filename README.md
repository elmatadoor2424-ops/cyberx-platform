## 🌟 مميزات المنصة الرئيسية (Key Features)

- **🎨 هوية بصرية نيون متقدمة (Dark Neon Cyber Theme)**:
  - ألوان متناسقة: Deep Slate (`#0B0F19`, `#0F172A`) مع توهجات نيون سماوية (`#00F0FF`) وأرجوانية (`#FF007F`).
  - تأثيرات Scanlines صوتية ومرئية تفاعلية.
- **⚡ كتالوج الخدمات السبع الأساسية (The 7 Core Services)**:
  1. تطوير المواقع والتطبيقات الذكية فائقة السرعة.
  2. الفيديوهات السينمائية الإعلانية (500 ج.م للفيديو / 2,000 ج.م لباقة 5 فيديوهات).
  3. التصاميم الاحترافية والبسترات والهوية البصرية.
  4. إدارة صفحات السوشيال ميديا وصناعة المحتوى الإبداعي.
  5. إدارة الحملات الإعلانية الممولة (1,200 ج.م للحملة / 2,000 ج.م لباقة حملتين).
  6. البرمجيات والأنظمة المخصصة (عيادات، مطاعم، نقاط بيع POS).
  7. أتمتة الواتساب والرد الذكي (1,500 ج.م/شهرياً + 1,000 رقم داتا مستهدفة مجاناً).
- **📊 جدول المقارنة الثلاثي الشفاف**:
  - مقارنة فورية بين (سعر السوق vs سعر CyberX vs سعر الخصم 70% بكود `CYBER70`).
  - محول عملات لحظي بين الجنيه المصري (EGP) والدولار الأمريكي (USD).
- **⭐ معرض التقييمات وقصص النجاح (Testimonials)**:
  - تقييمات موثقة 5 نجوم (5.0 / 5.0) من أصحاب مشاريع وعيادات ومطاعم.
- **🛡️ معرض سكرينات إثبات النتائج الحية (Proof Gallery)**:
  - لقطات شاشة موثقة لحملات Meta & TikTok Ads بعائد ROAS 7.8X ومبيعات المتاجر الإلكترونية مع نافذة تكبير وفحص Lightbox.

## 🛠️ البنية التقنية (Tech Stack)

- **Framework**: [Next.js 16](https://nextjs.org) (App Router + Turbopack)
- **Library**: [React 19](https://react.dev)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com) + Modern Vanilla CSS
- **Icons**: [Lucide React](https://lucide.dev)
- **Automation & Leads**: REST Webhook Engine متصل بـ n8n
- **State & Sync**: React Context API مع دعم المزامنة اللحظية

## 🚀 التشغيل والتطوير المحلي (Local Development)

```bash
# تثبيت الاعتماديات
npm install

# تشغيل خادم التطوير المحلي
npm run dev

# بناء نسخة الإنتاج
npm run build
```

افتح المتصفح على [http://localhost:3000](http://localhost:3000) لتصفح الموقع.
